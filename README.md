# Клинки эпох (Blade Duel)

Браузерная 3D-дуэль на мечах: клинком вы управляете **напрямую мышью** — кончик следует
за курсором, резкие движения превращаются в удары. Четыре эпохи на выбор, каждая со своей
ареной, оружием, освещением и генеративной музыкой.

## Эпохи

- **Мушкетёр** — рапира, двор замка на закате
- **Рыцарь** — палаш, ночной замковый двор с жаровнями
- **Самурай** — катана, сад на рассвете, падающие лепестки
- **Неон** — энергоклинок, арена будущего

## Управление

| Ввод | Действие |
| --- | --- |
| Мышь | клинок следует за курсором |
| Быстрое движение мышью | рубящий удар (урон зависит от скорости) |
| ЛКМ | колющий выпад |
| ПКМ (удерживать) | твёрдая защита: клинок медленнее, но окно парирования шире |
| W / S | сблизиться / отступить |
| A / D | обход влево / вправо |
| Esc / P | пауза |
| M | звук вкл/выкл |
| Space / Enter | начать дуэль, рестарт после боя |

## Основные системы

- **Клинок на мышке**: кончик клинка привязан к курсору через плоскость перед фехтовальщиком,
  инерция — экспоненциальным сглаживанием; рука позируется двухзвенной инверсной кинематикой.
- **Дистанция**: удары проходят только в пределах досягаемости; шаг назад или подшаг в сторону
  после замаха врага — реальный уворот.
- **Парирование**: атака врага телеграфируется красным бликом (точка перехвата + звук) —
  подставьте кончик клинка в точку до удара. Успешное парирование открывает врага для
  рипоста с двойным уроном.
- **ИИ противника**: держит дистанцию, обходит, защищается, атакует сериями; по мере потери
  здоровья агрессия растёт — замахи короче, появляются двойные удары.
- **Связка клинков**: быстрый контакт с клинком врага гасит вашу атаку (клинг) — пробивайте
  защиту обходом или после парирования.

## Запуск

```bash
npm install
npm run dev       # разработка (порт по умолчанию Vite)
npm run build     # продакшн-сборка в dist/
npm run preview   # локальный просмотр сборки
npm run verify    # браузерный смоук-тест сборки (Playwright)
npm run desktop   # запуск как десктопного приложения (Electron, нужна сборка)
npm run dist:win  # упаковка в portable .exe для Windows → release/blades-of-eras.exe
```

## Техника

Three.js, полностью процедурные модели (ни одного внешнего ассета): фигуры дуэлянтов,
арены, клинки; звук и музыка синтезируются Web Audio (звон, свист, удары, плюс
генеративная тема для каждой эпохи). Постобработка: ACES tone mapping + UnrealBloom
(свечение энергоклинков, жаровен, неона). Физика — Rapier (WASM): проигравший падает
настоящим рагдоллом на 11 телах со сферическими суставами, клинок отлетает отдельным
твёрдым телом; удары дают физический отброс. След клинка — лента на кольцевом буфере,
искры — пул частиц без аллокаций в горячем цикле, фиксированный шаг симуляции 60 Гц.

Десктопная версия — та же игра в окне Electron (общий код, `electron/main.cjs`).

Рекорды (победы/поражения/парирования по эпохам) хранятся в `localStorage` браузера.
